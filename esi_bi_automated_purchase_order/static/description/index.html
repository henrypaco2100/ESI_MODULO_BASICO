Automatizacion de la Orden de Compra Procesando el flujo de trabajo Odoo App

El proceso de orden de compra de Odoo requiere muchas acciones, como convertir una solicitud de cotizacion en una orden de compra, crear una factura de proveedor, validar la factura, registrar el pago de una factura. Normalmente, es necesario realizar estas acciones manualmente para completar una orden de compra. Proceso de flujo de trabajo de ordenes de compra automatizado La aplicacion Odoo proporciona un flujo de trabajo de configuracion para automatizar todos o algunos de estos procesos y acciones especificos. Una vez que el flujo de trabajo esta configurado, debe vincularse con la orden de compra y luego todos estos procesos se administraran en consecuencia con solo un clic. Segun la configuracion, el flujo de trabajo automatico llamara para cada orden de compra, lo que reducira la gran cantidad de tiempo y trabajo.

Caracteristicas

Orden de compra totalmente Automatizada

La orden de compra se confirmara y validara automáticamente con un solo clic.

Generar y validar automaticamente la factura del proveedor

Genere y valide automaticamente la factura del proveedor segun las configuraciones.

Autogenerar y Validar envio

Genera y Valide automaticamente la orden de envío segun las configuraciones.

Pago de registro automatico

El usuario tiene la opcion de registrar el pago automaticamente.

Politica de envios

El usuario puede elegir la opcion para seleccionar la política de envio para pedidos de compra especificos.

Compra/Diario de pago

El usuario tiene la opcion de seleccionar el diario de compras y el diario de pagos para los pedidos de compra.
Video Tutorial

Flujo de trabajo de Compra Automatica

Menu Facturacion> Configuraciones, el usuario puede ver y crear un flujo de trabajo automatico para la orden de compra..

Configuracion del flujo de trabajo de compra automatica

El usuario puede ver el flujo de trabajo automatizado creado para la orden de compra en la vista de arbol.

En el flujo de trabajo automatizado, el usuario debe seleccionar "Diario de compras" , "Diario de pagos", "Entregar a", "Secuencia de Compra y Secuencia de Cotizacion".

El usuario puede configurar las opciones de flujo de trabajo de la orden de compra como "Orden de validacion", "Seleccion de validacion", "Crear factura", "Vaciar factura" y "Registrar pago" y tambiEn seleccionar la politica de control.

Configuracion de cliente de flujo de trabajo de compra automatica

En la pestaña "Ventas y compras" del formulario de proveedor, el usuario debe habilitar "Es flujo de trabajo automatizado" y seleccionar "Proceso de flujo de trabajo".

Flujo de trabajo automatico en orden de compra

En la orden de compra se aplicara el flujo de trabajo automatizado del proveedor seleccionado.

El usuario tambien puede seleccionar manualmente el flujo de trabajo automatizado como se muestra en la imagen.

Boton de Auto Procesar

El usuario puede ver el boton "Auto Procesar" en el formulario de orden de compra.

Al hacer clic en el boton "Auto Procesar", el usuario puede ver que se confirma el pedido y que se crea la factura del proveedor y la seleccion con un solo clic.

Orden de Recepcion

El usuario puede ver el pedido de Recepcion validado y generado automaticamente.

Factura del Proveedor

El usuario puede ver la factura del proveedor automaticamente generada y validada, y el pago tambien registrado.
