Cancelar Orden de Producción

Con este modulo se puede cancelar las ordenes de producciones, anulando las operaciones realizadas en Informe de Inventario, Movimientos de existencias, Valoracion de Inventario entre otras operaciones realizadas por la orden de produccion.

Caracteristicas

Permiso de Acceso "Production/ Button Cancel"

Crea un nuevo permiso para cancelar la orden de Producción.

Cancelar Orden de Prodccion

Cancela una orden de producción anulando todos las operaciones realizadas por esta
